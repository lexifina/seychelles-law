# Article 1271

Novation is effected —

(a) When the debtor contracts with the creditor a new debt which is substituted for the earlier debt which is thereby extinguished;

(b) When a new debtor is substituted for the old, who is released by the creditor;

(c) When as a result of a new agreement, a new creditor is substituted for the old, in respect of whom the debtor is released.
