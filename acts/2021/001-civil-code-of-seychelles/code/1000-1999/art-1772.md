# Article 1772

(1) The tenant is liable for loss caused by an inevitable accident only if that is expressly provided for in the lease.

(2) Paragraph (1) —

(a) Includes ordinary inevitable accidents such as cyclonic winds, lightning, or drought;

(b) does not include extraordinary inevitable accidents, such as devastation caused by war or floods, unless the tenant has agreed to be liable for all extraordinary inevitable accidents, foreseen or unforeseen.
