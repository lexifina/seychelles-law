# Article 1917

(1) The deposit properly so called is in principle a gratuitous contract.

(2) It can apply only to movable property.

(3) It is only completed by actual or symbolic delivery of the property deposited.

(4) Symbolic delivery is sufficient when the depositary is already in possession, under some other title (titre), which it is agreed the depositary shall continue to hold by way of deposit. 1918, 1919 VACANT
