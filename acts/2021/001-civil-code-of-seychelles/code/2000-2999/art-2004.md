# Article 2004

(1) The principal may at any time revoke the agency and oblige the agent, if necessary, to return the document under private signature which contains the power or the original document conferring such power of attorney if it was drafted by a notary, or the notarially authenticated copy if a deed had been made.

(2) Nothing in paragraph (1) precludes the parties from agreeing to make the agency irrevocable for a fixed period or for a specific venture.

(3) The irrevocability of the agency may be implied from the object for which it provides or if the agent has a lawful interest in the object other than the regular remuneration due.
