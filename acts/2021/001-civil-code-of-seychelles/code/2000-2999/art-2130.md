# Article 2130

(1) If the available property of a debtor is insufficient for the security of the claim, the debtor may admit this insufficiency and agree that any property the debtor may subsequently acquire shall be used as security in the order of acquisition.

(2) If immovable property which is burdened with a mortgage perishes or suffers loss of value of a kind that renders it insufficient for the security of the creditor, the latter may either claim reimbursement forthwith or obtain an additional mortgage.
