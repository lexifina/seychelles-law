# Article 2132

(1) A conventional mortgage is valid only if the sum for which it has been granted is certain and fixed in the document of the grant.

(2) If the claim arising from the obligation is subject to a condition not yet fulfilled or of uncertain value, the creditor may make the inscription under this Code only to the extent of the estimated value of the claim as expressly declared by the creditor, subject to a reduction to be claimed by the debtor if appropriate.
