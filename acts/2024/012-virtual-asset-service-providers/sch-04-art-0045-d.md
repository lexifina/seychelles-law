# Article 45D

(1) For batch file virtual asset transfers from a single originator, section 45B(1) shall not apply to the individual transfers where —

(a) the transfers are bundled together as a batch file and the batch file includes —

(i) the name of the originator; and

(ii) location data concerning the originator as specified under section 45B(1)(c);

(b) where a wallet is used, the wallet address(es);

(c) where a wallet is not used to process virtual asset transfers, the unique transaction reference number (commonly known as a transaction hash) utilised for the tracing of the transfer.

(3) All information under subsection (1) should be transferred without delay to the beneficiary virtual asset service provider, together with transmission of the set of payment instructions to the beneficiary virtual asset service provider or to the beneficiary's financial institution.
